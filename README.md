# منظومة التوزيع الذكي لمراقبي الامتحانات 🎓
### جامعة القدس المفتوحة — فرع الخليل | قسم الامتحانات

منظومة ويب سحابية متطورة مصممة خصيصاً لأتمتة وتسهيل عملية جدولة وتوزيع مراقبي الامتحانات بجامعة القدس المفتوحة (فرع الخليل)، بالاعتماد على خوارزميات الذكاء الرياضي الإنساني ومراعاة راحة الكادر الأكاديمي وعدالة توزيع الكادر الإداري، مع مصفوفة تفريغ وطباعة A3 احترافية ومزامنة سحابية مع Google Cloud Firestore.

## 🌟 أبرز ما يميز المنظومة الحالية

1. **نسبة تغطية القاعات 100%:** إسناد كافة شواغر القاعات (415 قاعة من 415) بدون أي شاغر متبقٍ.
2. **استيفاء 100% لنصاب الكادر الأكاديمي:** الالتزام التام بأنصبة الـ 27 أكاديمياً كعقد ملزم بالكامل (الفرق = 0).
3. **تطبيق قاعدة الأنصبة القليلة (2 و 3 جلسات):** تجميع مراقبات أصحاب النصاب المحدود (مثل د. صالح الشلالفة، أ. لمياء عمرو، د. خالد النجار، أ. نور القواسمي) في **يوم واحد فقط** طيلة فترة الامتحانات.
4. **التجميع الثنائي للأكاديميين (Pair-First):** تفادي الجلسات المفردة وتركيز الحضور في كتل ثنائية متتالية (1+2 أو 2+3).
5. **ترقية اليوم الثلاثي لأصحاب الأنصبة الفردية:** تمكين الأساتذة ذوي الأنصبة الفردية (مثل د. عيسى المصري 13 جلسة) من أخذ يوم ثلاثي واحد لإنهاء الجلسات الفردية تماماً وتقليص أيام حضورهم إلى 6 أيام فقط.
6. **امتصاص الجلسات المفردة عبر الإداريين:** الاستفادة من تواجد الموظفين الإداريين في مكاتبهم بالحرم الجامعي لتغطية الجلسات الفردية الفائضة دون إرهاقهم (سقف عادل بحد أقصى جلستان يومياً).
7. **طباعة مصفوفة التفريغ بحجم A3 Landscape PDF:** تقرير متطابق بنسبة 100% مع ملف الإكسل المعتمد `مصفوفة_تفريغ_المراقبين_1261_نصفي.xlsx` مع ترويسة مزدوجة وتثبيت عمود الأسماء.
8. **المزامنة السحابية وبوابة المشاريع (Projects Hub):** حفظ وتخزين المشاريع في Google Cloud Firestore والتبديل المباشر بين الفصول والدورات.

## 🚀 التشغيل والبناء والنشر السريع

```powershell
# التشغيل المحلي
npm.cmd run dev

# الفحص والتدقيق الآلي (55 اختباراً برمجياً)
node scratch/audit_app.cjs

# البناء للإنتاج
npm.cmd run build

# النشر السحابي المباشر
npx.cmd firebase-tools deploy --only hosting
```
