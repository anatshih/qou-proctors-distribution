# نظام التوزيع الذكي لمراقبات الامتحانات — جامعة القدس المفتوحة 🎓

تطبيق ويب حديث ومتطور مصمم خصيصاً لأتمتة وتسهيل عملية جدولة وتوزيع مراقبي الامتحانات في جامعة القدس المفتوحة، مع مراعاة الأنصبة والاستثناءات ومنع التعارضات، وتوفير أدوات فلترة وطباعة وتصدير احترافية.

---

## 🌟 الميزات الرئيسية

1. **إدارة الكادر الدائم للمراقبين (43 مراقباً مدمجاً مسبقاً):**
   * إدخال وتعديل أعباء وأنصبة المراقبين لكل دورة امتحانية.
   * ميزة **تفعيل وتجميد (Active / Frozen)** لكل مراقب للدورة الحالية دون حذف اسمه من الكادر الدائم.
   * إمكانية إضافة مراقبين جدد، أو حذفهم، أو تصفير الأعباء لبدء دورة جديدة.

2. **إدارة الاستثناءات والاعتذارات (Exceptions Matrix):**
   * تحديد أوقات عدم التفرغ لكل مراقب بنقرة واحدة (استثناء يوم كامل أو جلسة محددة 1 أو 2 أو 3).
   * التزام تام بنسبة 100% بعدم وضع المراقب في أي وقت استثناه.

3. **جدول القاعات والجلسات (12 يوماً - 392 شاغر قاعة):**
   * تم استخراج الجدول الكامل مسبقاً ومطابقته لملف الفصل 1261.
   * إمكانية رفع أي ملف إكسل قاعات جديد وسحبه وإفلاته في أي وقت.

4. **محرك التوزيع الذكي (Constraint Satisfaction Engine):**
   * توزيع عادل يحقق النصاب المطلوب لكل مراقب.
   * منع أي تعارض زمني للمراقب في أكثر من قاعة بنفس الجلسة.
   * توزيع متوازن على مدار الأيام وتجنب إرهاق المراقب.

5. **الفلاتر والطباعة المنسقة الاحترافية (Print-Ready Layout):**
   * فلترة متعددة: حسب اسم المراقب، اليوم، الجلسة، القاعة، وحالة الإسناد.
   * **ميزة طباعة ما تم فلترته:**
     * طباعة بطاقة مراقبة فردية للمراقب لتوقيعه عليها.
     * طباعة كشف يومي للجنة الامتحانات.
     * طباعة الكشف الشامل.
   * ترويسة رسمية بشعار جامعة القدس المفتوحة وتنسيق صفحة A4 بدون تقطع.
   * تصدير ملفات إكسل منسقة لجدول القاعات ومصفوفة التفريغ.

6. **نظام الحسابات والأدوار:**
   * **مدير النظام (Super Admin / رئيس اللجنة):** تحكم كامل في إعدادات الفصل والامتحان، والنسخ الاحتياطي، وتصفير النظام.
   * **مسؤول الامتحانات (Admin):** التحكم التشغيلي في إدخال الأنصبة والاستثناءات والتوزيع والطباعة.

## 🚀 التشغيل المحلي (Local Development)

```bash
# تثبيت الحزم (إذا لزم الأمر)
npm install

# تشغيل خادم التطوير المحلي
npm run dev
```

افتح المتصفح على: `http://localhost:3000`

---

## 📦 بناء المشروع للإنتاج (Production Build)

```bash
npm run build
```

تُنشأ الملفات الجاهزة للنشر داخل مجلد `dist/`.

## 🌐 خيارات النشر السحابي (Deployment)

### 1. الرفع على GitHub:
```bash
git init
git add .
git commit -m "إطلاق نظام توزيع مراقبات الامتحانات - جامعة القدس المفتوحة"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO_NAME.git
git push -u origin main
```

### 2. النشر على Vercel (الأسهل والأسرع):
* بعد رفع الكود إلى GitHub، اذهب إلى [Vercel](https://vercel.com).
* اختر **Add New Project** ثم اربطه مع مستودع GitHub.
* سيتعرف Vercel على الإعدادات تلقائياً عبر ملف `vercel.json` المرفق، ويتم النشر بضغطة زر مجاناً.

### 3. النشر على Firebase Hosting:
```bash
npm install -g firebase-tools
firebase login
firebase init hosting
# (اختر مجلد dist كمجلد عام واسمح بـ Single Page App)
npm run build
firebase deploy
```
